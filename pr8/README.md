# ПР8. Виклик інструментів мовною моделлю («Сузірʼя»)

Проєкт клієнтського ІІ-помощника магазину «Сузірʼя» з підтримкою **виклику інструментів (tool calling / function calling)** мовною моделлю через OpenAI-сумісний API (Google Gemini).

Помічник відповідає на запитання клієнтів про:
- замовлення та їхні статуси;
- товари та їхні характеристики;
- наявність на складі та очікувані поставки;
- розрахунок вартості та строків доставки;
- оформлення заявок на повернення товарів.

Вся взаємодія будується на принципі **Zero Trust до моделі**: модель лише пропонує виклики інструментів, а програмний код бекенду перевіряє назву інструмента, валідність JSON, схему параметрів за JSON Schema, права доступу клієнта, мінімізує дані та виконує дозволені операції.

---

## 1. Вимоги до оточення

- **Python**: версія 3.10 або новіша (перевірено на Python 3.13).
- **ОС**: Windows, Linux, macOS.
- **Google AI Studio API Key**: для доступу до моделей Gemini (через OpenAI-сумісний ендпоінт).

---

## 2. Встановлення та налаштування

### 2.1. Створення віртуального оточення та встановлення залежностей

```bash
cd pr8
python -m venv .venv

# Активація для Windows (PowerShell):
.venv\Scripts\Activate.ps1

# Активація для Linux / macOS:
source .venv/bin/activate

# Встановлення пакетів:
pip install -r requirements.txt
```

### 2.2. Налаштування файлу `.env`

Скопіюйте зразок `.env.example` у `.env`:

```bash
# Windows:
copy .env.example .env

# Linux / macOS:
cp .env.example .env
```

Заповніть змінні у файлі `.env`:

```ini
# Базовий URL OpenAI-сумісного ендпоінта Gemini
LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/

# API-ключ із Google AI Studio (https://aistudio.google.com)
LLM_API_KEY=ваш_ключ_тут

# Модель (рекомендовано: gemini-3.5-flash-lite або gemini-3.8-flash)
LLM_MODEL=gemini-3.5-flash-lite

# Параметри генерації
LLM_TEMPERATURE=0
LLM_MAX_TOKENS=1000
LLM_TIMEOUT=60

# Ліміт раундів звертань до моделі на одне питання клієнта
TOOL_MAX_ROUNDS=5

# Фіксована дата сервісу магазину
SHOP_TODAY=2026-10-06

# Імітація повільного та ненадійного сервісу
SHOP_DELAY_MS=0
SHOP_FAILURE_RATE=0
```

## 3. Перевірка оточення

Перед запуском перевірте готовність системи:

```bash
python check_env.py
```

Скрипт перевірить версію Python, наявність пакетів, з'єднання з API, валідність ключа і здатність моделі викликати тестовий інструмент `get_exchange_rate`.

---

## 4. Запуск веб-застосунку

Запуск веб-сервера FastAPI (з папки `pr8`):

```bash
uvicorn app.main:app --reload
```

Після запуску відкрийте браузер за адресою:
👉 **http://127.0.0.1:8000**

У веб-інтерфейсі доступні:
1. **Вибір клієнта** (імітація сеансу: Олена Коваль `C-1001`, Андрій Мельник `C-1002`, Ірина Бондар `C-1003`).
2. **Поле введення запитання**.
3. **Кнопка скидання даних магазину** («скинути дані магазину»).
4. **Блок відповіді помічника**.
5. **Журнал викликів інструментів** (статуси `виконано`, `відхилено`, `помилка`, аргументи моделі, повернутий результат, час виконання).
6. **Метадані**: назва моделі, кількість раундів, час моделі та інструментів, статистика токенів.
7. **Описи інструментів**, які бачить модель (`GET /api/tools`).

## 5. Запуск автоматичних тестів

Запуск тестового набору `pytest` (27 тестів):

```bash
pytest -v
```

Тести покривають:
- Генерацію схем інструментів (`specs`).
- Рівні безпеки Level 1–6 (відхилення заборонених інструментів, невалідного JSON, невідповідності схемі, відсутніх полів, чужих замовлень).
- Нормалізацію номерів замовлень (`№ 10 458` -> `10458`).
- Мінімізацію даних (видалення `internal_note`, `operator_notes`, маскування карток).
- Запобігання повторному оформленню повернення (ідемпотентність).
- Обробку помилок сервісу магазину (`NotFound`, `PolicyViolation`, `Unavailable`).
- Цикл взаємодії асистента (`app.assistant`), облік часу та токенів, збереження `tool_call_id`.
- Веб-маршрути FastAPI (`/`, `/api/customers`, `/api/tools`, `/api/ask`, `/api/reset`).
- Захист від prompt injection у даних каталогу та користувацьких запитах.

---

## 6. Запуск оцінювання та експериментів

Скрипт оцінювання запускає набір із 20 тестових запитань (15 зразкових + 5 власних граничних і захисних сценаріїв) зі скиданням стану перед кожним питанням:

```bash
# Базовий прогін:
python eval/run_eval.py --output eval/results_baseline.json

# Прогін експерименту:
python eval/run_eval.py --output eval/results_experiment.json

# Прогін з ненадійним сервісом магазину (SHOP_FAILURE_RATE=0.3):
python eval/run_eval.py --failure-rate 0.3 --output eval/results_unreliable.json
```

### Розташування звітів:
- `eval/questions.json` — тестовий набір запитань.
- `eval/results_baseline.json` — результати базового оцінювання.
- `eval/results_experiment.json` — результати після покращення опису інструмента.
- `eval/results_unreliable.json` — результати при збоях магазину (`SHOP_FAILURE_RATE=0.3`).
- `eval/findings.md` — аналітичний звіт з висновками, таблицями та відповідями на контрольні запитання.

├── eval/
│   ├── questions.json         # Тестові питання (20 шт.)
│   ├── run_eval.py            # Автоматизована оцінка та формування метрик
│   ├── results_*.json         # Результати прогонів

├── .gitignore                 # Виключення секретів і кешу
└── check_env.py               # Діагностика середовища

## 8. Відомі обмеження

1. **Ідемпотентність повернень**: реалізована на рівні перевірки наявних записів у `service.list_returns(order_id)` за комбінацією `order_id + sku + reason`. Оскільки внутрішній сервіс `shop.service` генерує новий `return_id` на кожен виклик, захист від дублікатів реалізовано у програмному шарі `tools.py`.
2. **Сесії клієнтів**: у навчальному додатку вибір клієнта здійснюється у селекторі сторінки замість повноцінної сесійної cookie-автентифікації. Проте бекенд суворо ізолює запити за переданим `customer_id` і ніколи не дозволяє моделі змінювати або обирати власника замовлення.
3. **Квоти Google AI Studio (Free Tier)**: безкоштовний тариф Gemini має обмеження у 15 запитів за хвилину (RPM). У модуль `app/llm.py` вбудовано експоненційний backoff та повторні спроби, а в `eval/run_eval.py` додано паузи між питаннями для стабільного проходження тестів без помилок 429.
